# FormFlow

Fill, sign and export PDF forms privately, on your own device.

- **Open any PDF:** FormFlow finds the fields, AcroForm or flat, in English,
  Hebrew and other languages.
- **Guided filling:** step through the fields one at a time.
- **Annotate freely:** text, check marks, dates, freehand ink, highlights and
  signatures, anywhere on the page.
- **Export a new, flattened copy:** the original file is never changed.

Desktop app for macOS and Windows, built with Tauri 2, React and TypeScript.
Documents never leave the machine.

## Quick start

Requirements:

- Node 24;
- Rust stable (only for the desktop app);
- on Windows, the WebView2 runtime, which is preinstalled on Windows 11.

```bash
npm install
```

```bash
npm run app:dev
```

`npm run dev` serves the same UI in a browser at http://localhost:1420. It uses
the File System Access API, or plain upload and download where that isn't available.

## Commands

| Command | What it does |
| --- | --- |
| `npm run app:dev` | Desktop app with hot reload |
| `npm run app:build` | Release bundle (`.app`/`.dmg` on macOS, `.msi`/NSIS on Windows) in `src-tauri/target/release/bundle/` |
| `npm run dev` / `npm run build` | Browser dev server / production web build |
| `npm test` | Unit and integration tests (Vitest; generates fixtures first) |
| `npm run test:e2e` | Playwright end-to-end tests in Chromium (starts the dev server) |
| `npm run detect:eval` | Detection precision/recall on the fixtures (`-- --details` lists misses) |
| `npm run lint` · `npm run typecheck` | ESLint · TypeScript |
| `cd src-tauri && cargo test` | Rust file-access tests |
| `npm run fixtures` | Writes the test PDFs and their ground truth to `tests/fixtures/out/` |

## Rebranding

1. **Name, tagline and storage prefix:** `src/brand.ts`. Changing the prefix resets
   saved local data.
2. **Desktop app:** `productName`, `identifier` and the window `title` in
   `src-tauri/tauri.conf.json`, and `<title>` in `index.html`.
3. **Icon:** replace `branding/app-icon.svg` (1024×1024), then regenerate the icons:

   ```bash
   npx tauri icon branding/app-icon.svg
   ```

   Also update `public/favicon.svg` and `src/shell/LogoMark.tsx`, the in-app mark.
4. **Colours:** the accent and the rest of the palette are design tokens in
   `src/styles/tokens.css`, with light and dark themes.

## Testing

The tests run against real PDFs generated by `tests/fixtures/forms.ts`:

- **Unit tests:** the model, text layout and bidi, detection stages, the editor, and
  signature processing.
- **Integration tests:**
  - export placement on rotated, cropped and offset pages, verified by rendering
    the output and locating the ink;
  - Unicode and RTL text extraction;
  - native-field replacement;
  - encrypted files.
- **Rust:** path validation, the PDF header check, save-target rules, atomic writes
  and grants.
- **End to end (Playwright):**
  - guided fill and export, with the downloaded PDF re-read by pdf.js;
  - AcroForm, Hebrew and signature export;
  - undo and redo;
  - error messages for bad files;
  - the password prompt;
  - restoring or discarding saved progress.

CI (`.github/workflows/ci.yml`) runs all of this on macOS and Windows, then builds
unsigned desktop bundles.

## Known limitations

- **Detection:** no OCR, so scanned pages get no field suggestions. The text and
  annotation tools still work on them. Detection accuracy is measured only on our
  own fixtures; see [detection.md](docs/detection.md).
- **Signatures:** visual only, not cryptographic.
- **Encrypted PDFs:** these can only be exported as a flattened copy, in which the
  original pages become images.
- **Form scripts:** XFA forms and form JavaScript are not supported. Calculated
  fields don't recalculate.
- **Distribution:** desktop bundles are unsigned. Code signing and notarisation
  need your own certificates.
